# HauenthalVR

A collaborative Unity VR project visualizing the redesigned Hauenthal mobility station in 360°.  
This project combines **VR prototyping, UX redesign, and usability testing** to reimagine passenger information systems for future mobility stations in Germany.  

---

## 🚉 Project Overview
- Redesigned the Hauenthal mobility station layout and passenger information system.  
- Built an immersive **VR environment** of the redesigned station for evaluation.  
- Conducting **usability testing in VR** to gather insights on passenger experience, accessibility, and clarity of information flow.
